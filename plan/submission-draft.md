## 2. 본문 초안 (02 섹션에 들어갈 글)

**앱명 / 프로젝트명:** Car Studio ⚠️ (가칭. 한글 후보 "차 안 스튜디오" / "주차장 스튜디오")

### 1. 앱 한 줄 소개

안 A (추천):
> 주차된 차의 디스플레이와 실내 조명을 스튜디오 조명으로, 거치한 폰의 화면을 모니터로, 다이얼을 컨트롤러로 묶어, 쓰던 카메라·라이브 앱 그대로 차 안에서 촬영하게 하는 앱.

안 B:
> 충전·픽업을 기다리는 차 안을, 폰은 그대로 두고 다이얼로 조명을 맞추는 1인 스튜디오로 바꿉니다.

### 2. 기획 배경

차 안은 이미 사람들이 사진과 영상을 찍는 곳입니다. 창으로 들어오는 빛과 혼자 있을 수 있는 공간 때문에 "차에서 찍은 셀카·브이로그·라이브·영상통화"는 흔한 장면이 되었고, 전기차 충전 20~40분, 아이 학원 픽업 대기, 출근 전 주차장에서의 외모 점검과 화상회의처럼 **차에 앉아 기다리는 시간**은 반복해서 생깁니다.

그런데 그 시간에 차는 스튜디오로서 네 가지가 불편합니다.

1. **조명이 없다.** 밤, 지하주차장, 비 오는 날에는 빛이 없고, 실내등은 머리 위에서 내려와 눈 밑에 그림자를 만들고 색도 누렇습니다.
2. **보면서 찍을 수 없다.** 폰을 거치대에 두면 화면이 작고 멀어서 구도·표정·라이브 댓글을 확인하기 어렵습니다.
3. **조절하려면 폰을 만져야 한다.** 밝기를 바꿀 때마다 폰을 건드리면 맞춰 둔 구도가 틀어집니다.
4. **장비를 들고 다니지 않는다.** 휴대용 링라이트와 모니터는 차에 두고 다닐 물건이 아닙니다.

반면 차는 스튜디오의 부품을 이미 갖고 있습니다. 얼굴 정면 높이에 있는 **넓은 중앙 디스플레이**(면광원), 색을 바꿀 수 있는 **앰비언트 라이트**와 좌석별 **실내등·독서등**(배경·보조광), 손을 떼지 않고 돌리는 **다이얼**(컨트롤러), 그리고 **닫힌 개인 공간**입니다. 모바일 앱으로는 이 조합을 만들 수 없습니다. 폰은 카메라 역할을 하는 순간 자기 화면을 조명으로 쓸 수 없고, 앰비언트·실내등·다이얼은 차에만 있기 때문입니다. 카메라와 촬영 앱은 사용자가 이미 갖고 있습니다. 필요한 것은 차의 부품들을 "촬영"이라는 하나의 용도로 묶어 주는 앱입니다.

### 3. 앱 주요 기능 및 차량 특화 요소

차량 앱(Pleos Connect)과 폰 동반 앱으로 구성됩니다. **차량 앱이 조명·모니터·조작을, 폰 동반 앱은 백그라운드에서 폰 화면 송출만** 맡습니다. 촬영·저장·라이브 송출은 사용자가 쓰던 폰 앱(기본 카메라, 틱톡, 유튜브 라이브, 화상회의 앱 등)이 그대로 합니다.

| 기능 | 내용 | 차량 특화 요소 |
|---|---|---|
| 스튜디오 모드 | 앱을 열면 센터 디스플레이가 링라이트 + 모니터 + 조명 패널의 스튜디오 화면으로 바뀝니다 | 디스플레이·조명·다이얼을 한 용도로 묶음 |
| 링라이트 | 앱 영역 가장자리를 발광 테두리로 씁니다. 밝기를 올리면 테두리가 두꺼워지고 화면 밝기가 최대가 됩니다. 빛은 **색온도**(2700K 따뜻한 빛 ~ 6500K 흰빛)로 맞추고, 무드 색(시안·블루·퍼플)은 프리셋으로 고릅니다 | 얼굴 정면 높이의 넓은 디스플레이가 광원. 폰 세로 화면을 가운데 두면 좌우 여백이 커져 광원 면적이 늘어남 |
| 폰 화면 미러링(모니터) | 거치대에 둔 폰의 화면을 차 화면 가운데에 크게 띄웁니다. 카메라 미리보기, 라이브 댓글, 회의 참가자 화면이 그대로 보입니다. 폰을 연결하면 자동으로 붙고 끊기면 다시 붙습니다 | 큰 화면 = 리턴 모니터. 폰은 손대지 않고 봅니다 |
| 차량 조명 상태 관리(조명 패널) | 앰비언트(색·밝기·켜짐), 실내등, 좌석별 독서등의 현재 상태를 한 패널에 보여 주고 전환합니다. 링라이트와 같은 색온도·밝기를 앰비언트에도 넣어 톤을 맞춥니다(테두리가 키라이트, 앰비언트가 배경광) | Vehicle SDK Light 도메인 조회·설정 |
| 다이얼 조절 | 다이얼을 돌려 밝기나 색온도를 바꿉니다. 조절 대상(밝기 ⇄ 색온도)은 전환할 수 있습니다. 다이얼은 조명 전용이고 폰 조작은 폰에서 합니다 | 물리 컨트롤러. 폰과 구도를 건드리지 않습니다 |
| 폰에서도 조절 | 폰 앱 화면에서 밝기·색온도를 조절하고, 촬영 앱을 쓰는 중에는 알림의 '따뜻하게·차갑게' 버튼으로 바꿉니다. 차와 폰이 같은 값을 공유해 어느 쪽에서 바꿔도 링라이트·앰비언트·상대편 화면에 함께 반영됩니다 | 차의 조명을 폰에서, 폰의 화면을 차에서. 두 기기가 하나의 스튜디오 |
| 조명 씬 (2차 범위) | 링라이트+앰비언트+실내등 조합을 한 번에 고르는 프리셋(예: 데일리·웜 뷰티·쿨 시네마·네온) | 세 광원을 묶어야 가능한 기능 |
| 풀 라이트 모드 (2차 범위) | 미러링을 숨기고 화면 전체를 조명으로 씁니다. 폰 화면을 직접 봐야 할 때 | 디스플레이 전체를 광원으로 |
| 정차 전용 | 기어가 P 또는 N일 때만 동작합니다. 주행 기어(D·R)로 바뀌면 경고를 띄우고 3초 뒤 종료하며, 주행 기어에서는 실행해도 바로 종료됩니다 | 기어 상태 연동 |
| 원래대로 복원 | 시작할 때 조명 원래 값을 읽어 두고, 종료(정상·기어 전환 포함) 시 되돌립니다 | 차량 설정을 어지럽히지 않음 |
| 저장·전송 없음 | 폰 화면은 폰→차 연결 구간에서만 흐르고 우리 앱은 서버·저장·위치 수집이 없습니다. Android의 "앱 하나만 공유"를 쓰면 촬영 앱 화면만 차에 보입니다 | 차 안에서 끝나는 프라이버시 |

새로운 경험: 기다리는 시간에, 장비 없이, 추가 비용 없이, 쓰던 앱 그대로, 폰에 손대지 않고 조명을 맞춰 찍고, 내리면 차는 원래대로 돌아옵니다.

### 4. 주요 사용 시나리오

**시나리오 1 — 충전 대기 중 라이브 방송.** 20대 후반 직장인, 전기차로 출퇴근, 주 1~2회 공용 충전소에서 30분 대기.
1. 충전 케이블을 꽂고 기어는 P. 차에서 앱을 실행하면 차량 상태를 확인한 뒤(P) 스튜디오 화면이 열립니다.
2. 폰을 거치대에 올리고 차와 연결합니다. 폰에서 Car Studio를 켜 "화면 공유 시작"을 누르고(시스템 동의) 홈으로 나갑니다. 폰 앱은 백그라운드로 갑니다.
3. 폰에서 틱톡 라이브를 켭니다. 차 화면 가운데에 라이브 화면이 크게 뜹니다. 자기 얼굴과 시청자 댓글이 함께 보입니다.
4. 지하주차장이라 어둡습니다. 다이얼을 돌려 밝기를 80%로, 눌러 색온도 모드로 바꾼 뒤 몇 칸 돌려 3500K의 따뜻한 빛으로. 앰비언트도 같은 톤으로 바뀌어 배경이 정리됩니다. 조명 패널에서 독서등은 끕니다(머리 위 그림자). 방송 중에 폰 알림의 '차갑게'를 눌러도 같은 값이 차에 반영됩니다.
5. 방송은 틱톡에서 평소처럼 진행하고 끝냅니다. 촬영·송출·저장은 전부 틱톡이 합니다.
6. 충전이 끝나 기어를 D로 옮기면 "주행 기어에서는 사용할 수 없어 종료합니다" 안내 후 앱이 닫히고, 앰비언트·실내등은 원래 값으로 돌아갑니다.

**시나리오 2 — 출근 전 화상회의 5분.** 회사 지하주차장에 도착해 차에서 짧은 회의에 들어갑니다. 폰 카메라는 얼굴을 향하고, 회의 앱 화면(참가자·공유 자료)은 차 화면에 크게 미러링됩니다. 다이얼로 밝기만 맞춥니다. 회의가 끝나고 시동을 끄면 앱이 종료되며 조명이 복원됩니다.

**시나리오 3 — 주행 중 실행 시도.** 신호 대기 중 앱을 열면 기어가 D이므로 조명을 켜지 않은 채 안내 후 바로 종료됩니다. 조명·앰비언트는 건드리지 않습니다.

주행 중/정차 중 구분: 이 앱은 **정차(P·N) 전용**입니다. 주행 중에는 어떤 기능도 동작하지 않도록 설계했고, 정차→주행 전환을 감지해 스스로 종료합니다.

### 5. 개발 계획

**구성**

| 구성 요소 | 내용 |
|---|---|
| 차량 앱 | Pleos Connect(AAOS API 34) 앱. Kotlin, Jetpack Compose + car-ui-lib(다이얼). 스튜디오 모드·링라이트·조명 패널·미러링 표시·정차 확인 담당 |
| 폰 동반 앱 | Android 앱. `MediaProjection`으로 화면을 캡처해 포그라운드 서비스(백그라운드)에서 송출. 카메라를 잡지 않으므로 어떤 촬영·라이브 앱과도 같이 씀 |
| 연결 | 1차 **유선(USB)**, 2차 무선(Wi-Fi·폰 핫스팟). 차량 앱이 폰에 접속하며, 연결 하나로 영상 프레임(폰→차)과 조명 값(양방향)을 메시지로 주고받습니다. 전송 계층을 분리해 두어 USB 테더링(IP)이든 USB 액세서리 모드(바이트 스트림)든 같은 앱 로직이 동작합니다 ⚠️ 실차 USB 경로는 Pleos 확인 중(아래 리스크) |
| 서버 | 없음. 위치·개인정보 수집 없음 |

**SDK/API 사용 계획**

| 용도 | SDK / API | 제공 상태(2026-10-28 Playground 기준) |
|---|---|---|
| 조명 지원 범위 확인 | Vehicle SDK v2.3.2 Light `checkAmbientLightBrightnessCapabilities`, `checkAmbientLightBrightnessColorCapabilities`, `checkAmbientLightSwitchCapabilities`, `checkCabinLightSwitchCapabilities`, `checkReadingLightSwitchCapabilities` | 사용 가능 |
| 조명 원래 값·현재 상태 읽기 | `getAmbientLightBrightness`, `getAmbientLightBrightnessColor`, `getAmbientLightSwitch`, `getCabinLightSwitch`, `getReadingLightSwitch`(좌석별) | 사용 가능 (Vehicle State) |
| 조명 설정·복원 | `setAmbientLightBrightness`, `setAmbientLightBrightnessColor`, `setAmbientLightSwitch`, `setCabinLightSwitch`, `setReadingLightSwitch` (스위치 값 `LightSwitch.OFF/ON/AUTOMATIC`) | Vehicle Control "준비 중". 앰비언트 set은 에뮬레이터 2.1.0에서 `CONTROL_CAR_LIGHTS` 권한으로 동작 확인 |
| 외부 변경 추적(패널 동기화) | `registerAmbientLightBrightnessListener`, `registerAmbientLightBrightnessColorListener`, `registerCabinLightState`, `registerReadingLightState` | 사용 가능 |
| 기어(P/N/D/R) | AAOS Car API `CarPropertyManager` `GEAR_SELECTION` 구독 (Pleos SDK에 기어 API 없음) | 에뮬레이터 확인 |
| 다이얼 입력 | car-ui-lib `FocusArea`·`FocusParkingView`·직접 조작 모드(`ACTION_SCROLL_FORWARD/BACKWARD`) | 에뮬레이터 확인 |
| 폰 화면 미러링 | 폰: Android `MediaProjection` + 가상 디스플레이(축소 해상도) → JPEG 프레임 · 차: 표준 라이브러리 수신·표시 | 수신·표시 경로 확인(카메라 소스). 미러링 소스 교체는 진행 중 |
| 폰↔차 조명 동기화 | 미러링과 같은 연결 위에 조명 값 메시지(양방향). 색온도(K)는 흑체 복사 근사식으로 RGB로 바꿔 링라이트와 `setAmbientLightBrightnessColor`에 같은 값으로 적용 | 구현 예정(1차) |
| 확장(후순위) | SpeechToText SDK(포즈 잡은 채 "더 밝게" 음성 조절), TextToSpeech SDK(종료 안내 음성) | 준비 중. 핵심 기능이 의존하지 않음 |

**권한:** `pleos.car.permission.CAR_LIGHTS`(조명 조회), `pleos.car.permission.CONTROL_CAR_LIGHTS`(조명 설정), `android.car.permission.CAR_POWERTRAIN`(기어), `INTERNET`(폰 연결). 폰 앱: `FOREGROUND_SERVICE_MEDIA_PROJECTION`, 화면 캡처 사용자 동의.

**플랫폼 정책 대응:** 주행 중 사용 불가(Distraction Optimized 미선언, 정차 전용 설계로 일치) · 차량 앱은 백그라운드 동작·알림·타이머 없음 · 서버·위치 없음 · 종료 시 차량 조명 원복 · 미러링은 정차 중에만, 사용자가 공유 범위(전체/앱 하나)를 고름.

**이미 검증한 것 (Pleos Connect 에뮬레이터 2.1.0 + 폰 에뮬레이터, 2026-11-04~08)**
- 폰 → 차 영상 수신·표시 약 30fps, 자동 접속·재접속 (카메라 소스 기준. 미러링 소스는 같은 경로로 교체 예정).
- 앰비언트 원래 값 읽기 → 스튜디오 값 설정 → 종료 시 복원.
- 다이얼 회전으로 밝기·색 조절.
- 기어 P에서 동작, D·R 전환 시 3초 뒤 종료, D에서 실행 시 즉시 종료.
