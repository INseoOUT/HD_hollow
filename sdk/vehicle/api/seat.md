Provides APIs for seat position, occupancy, seat belt, and seat climate.

- 획득: `vehicle.getSeat()` ([원본](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle/ai.pleos.playground.vehicle/vehicle/get-seat))
- 권한: 조회 `pleos.car.permission.CAR_SEATS` · 제어 `pleos.car.permission.CONTROL_CAR_SEATS`
- 함수 101개 (deprecated 15개 포함), 리스너 15개
