Provides APIs for climate control (HVAC).

- 획득: `vehicle.getHVAC()` ([원본](https://document.pleos.ai/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle/ai.pleos.playground.vehicle/vehicle/get-h-v-a-c))
- 권한: 조회 `pleos.car.permission.CAR_CLIMATE` · 제어 `pleos.car.permission.CONTROL_CAR_CLIMATE`
- 함수 86개 (deprecated 14개 포함), 리스너 12개
